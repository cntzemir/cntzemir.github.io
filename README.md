## What This Portfolio Is Trying to Show

My recent work is intentionally moving away from generic “student web demos” and toward smaller but more deliberate projects that show how systems can be built with security-aware decisions from the start.

Rather than only building UI flows, I aim to demonstrate:

- backend-enforced access control
- auditable workflows and visible system behavior
- defensive validation and safer request handling
- role separation and controlled state transitions
- practical Linux hardening with verification and tradeoff awareness
